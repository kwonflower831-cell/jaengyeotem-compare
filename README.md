# 쟁여템 가격비교

자주 쓰는 물건을 같은 기준(1개 값, 100ml 값, 1kg 값 등)으로 맞춰 비교한 글 모음 사이트예요.

사이트: https://kwonflower831-cell.github.io/jaengyeotem-compare/

## 페이지
- index.html: 처음 화면
- coupang.html: 쿠팡 파트너스 링크가 들어 있는 비교 글 목록
- naver.html: 네이버 쇼핑 커넥트 링크가 들어 있는 비교 글 목록
- tips.html: 제휴 링크가 없는 생활 꿀팁 목록
- graph.html: 단가 비교 그래프

## 알아 둘 점
- 쿠팡, 네이버 페이지 맨 위에는 수수료 문구를 일반 글자로 적어 둡니다. 한 페이지에는 한 제휴 서비스만 씁니다.
- 가격과 할인은 수시로 바뀝니다. 판매 페이지에서 현재가를 확인하세요.
- 비교는 글에 적은 범위(예: 5종) 안에서의 순서이고, 맛이나 품질은 비교하지 않습니다.

## 운영 순서 (아침에 몰아서)
1. 가격을 상품 페이지에서 직접 확인하고 기준일을 적는다.
2. 블로그 글을 올린다.
3. 같은 글을 사이트 목록 페이지에 추가한다.
4. 그래프 페이지의 기준일과 값을 맞춘다.
5. 사이트에 반영됐는지 확인한다.
